# Dataset

The original Google Colab notebook reads `parameters.csv`, which was **not included** in the recovered uploads. To reproduce the original work, retrieve the dataset from its original authorized source and save it as `data/parameters.csv` (or provide any CSV path to the CLI).

Required columns: `speed`, `altitude`, `payload` (units in the original slides: m/s, m, grams). Extra columns are allowed. Do not confuse the 209 flight recordings described in the presentation with the number of rows in a reconstructed CSV.

Please verify the original CMU dataset citation and sharing terms before redistributing it.
